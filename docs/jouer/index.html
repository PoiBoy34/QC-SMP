Jouer à LQDM

Viens jouer avec nous

Sur PC, télécharge le launcher : il installe tout et te connecte directement au serveur. Sur console ou téléphone, rien à installer.

{% include icone.html nom="telecharger" %}Télécharger pour Windows
Gratuit · Windows 10 et 11
Sur Linux ? Prends la version AppImage
1

Télécharge et installe

Clique sur le gros bouton blanc, puis ouvre le fichier téléchargé et suis l'installation.

2

Connecte-toi

Ouvre LQDM et connecte-toi avec ton compte Microsoft, celui avec lequel tu as acheté Minecraft.

3

Clique sur Jouer

La première fois, le téléchargement prend quelques minutes. Ensuite, le jeu s'ouvre et t'amène directement au spawn.

Un écran bleu « Windows a protégé votre ordinateur » ?

C'est normal : Windows affiche ça pour tous les petits programmes qu'il ne connaît pas encore. Ce n'est pas un virus.

  1. Clique sur Informations complémentaires.
  2. Puis sur Exécuter quand même.

Si Chrome ou Edge bloque le téléchargement : clique sur les trois points à côté du fichier, puis sur Conserver. Tous les détails : Windows bloque le launcher.

1

Ajoute le serveur en ami

Dans Minecraft : Jouer, onglet Amis, puis Ajouter un ami.

{%- if site.lqdm.gamertag != "" %}

Cherche ce nom :

{{ site.lqdm.gamertag }}
{%- else %}

Le nom du compte du serveur sera bientôt annoncé ici et sur le Discord.

{%- endif %}
2

Attends l'invitation

Le serveur accepte ta demande tout seul. Ça peut prendre une minute.

3

Rejoins la partie

Retourne dans l'onglet Amis : le serveur apparaît dans les parties qu'on peut rejoindre. Sélectionne-le et clique sur Rejoindre.

Avant de commencer

Minecraft doit être à jour et connecté à ton compte Microsoft. Sur PlayStation et Switch, le jeu en ligne peut demander un abonnement (PS Plus, Nintendo Switch Online).

Tu as un compte enfant ? Un parent doit autoriser le jeu multijoueur, le jeu multiplateforme et les amis dans Microsoft Family Safety (ou dans les paramètres de confidentialité Xbox), sinon le serveur n'apparaîtra pas. Plus d'aide : le serveur n'apparaît pas sur ma console.

1

Ouvre les serveurs

Dans Minecraft : Jouer, onglet Serveurs, puis tout en bas Ajouter un serveur.

2

Entre l'adresse

3

Rejoins

Enregistre, puis touche le serveur pour le rejoindre. Accepte le pack de textures si le jeu te le propose.

La version « Minecraft pour Windows » (Bedrock) se connecte de la même façon, avec l'adresse et le port ci-dessus.

Questions

Le serveur me dit que je ne suis pas sur la liste blanche

Le serveur est privé. Demande à être ajouté dans le salon #support du Discord ou à {{ site.lqdm.contact }}, en donnant ton pseudo (ton gamertag si tu joues sur console, téléphone ou tablette).

Est-ce que le launcher est gratuit ? Est-ce un virus ?

Il est gratuit et ce n'est pas un virus : son code est public sur GitHub, et le fichier est fabriqué automatiquement à partir de ce code. Il te faut quand même ton propre compte Minecraft.

Est-ce que je peux jouer sans le launcher ?

Oui : dans Minecraft Java, va dans Multijoueur et ajoute l'adresse {{ site.lqdm.adresse }}. Le launcher installe en plus les mods qui rendent le jeu plus fluide et te connecte directement.

J'ai un Mac

Le launcher n'existe pas encore sur Mac. Tu peux jouer avec Minecraft Java en ajoutant l'adresse du serveur dans Multijoueur.

Ça ne marche pas, qu'est-ce que je fais ?

Dans le launcher : ⚙️ Paramètres, puis Aide et diagnostic, puis Copier le rapport de diagnostic. Colle-le dans le salon #support du Discord ou envoie-le à {{ site.lqdm.contact }}, avec une capture d'écran du message d'erreur. Voir aussi la page Support.

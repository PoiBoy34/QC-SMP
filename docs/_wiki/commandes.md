Tout ce qui suit marche sur PC, sur console et sur téléphone : tape la commande dans le chat.
Le plus simple reste le [menu LQDM](/wiki/menu-lqdm/).

## Partout sur le serveur

| Commande | Ce qu'elle fait |
|---|---|
| `/menu` ou `/m` | Ouvre le menu LQDM |
| `/spawn` (ou `/hub`, `/lobby`) | Retour au spawn |
| `/smp` (ou `/survie`) | Va sur le serveur de survie |
| `/games` (ou `/jeux`) | Le menu des mini-jeux |
| `/rules` (ou `/regles`) | Les règles |

## Sur la survie

| Commande | Ce qu'elle fait |
|---|---|
| `/rtp` | Téléportation à un endroit au hasard |
| `/sethome <nom>` | Crée un home là où tu es |
| `/home <nom>` | Va à un de tes homes |
| `/homes` | La liste de tes homes |
| `/delhome <nom>` | Supprime un home |
| `/tpa <pseudo>` | Demande à aller chez un joueur |
| `/tpahere <pseudo>` | Demande à un joueur de venir chez toi |
| `/tpaccept` / `/tpdeny` | Accepte ou refuse une demande |
| `/back` | Retour là où tu étais avant ta dernière téléportation |

Tapées ailleurs que sur la survie, ces commandes t'y emmènent : refais-la une fois arrivé.

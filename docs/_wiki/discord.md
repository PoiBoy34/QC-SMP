Le Discord, c'est là que vit la communauté LQDM : les annonces, les événements, l'entraide.

**Rejoindre le Discord : <{{ site.lqdm.discord }}>**

## À quoi il sert

- **Les annonces** : nouveautés, événements, mises à jour du serveur.
- **#support** : tu bloques ? Pose ta question, quelqu'un de l'équipe te répondra.
- **Discuter** avec les autres joueurs, organiser des parties, montrer tes constructions.
{% if site.lqdm.salon_tchat != "" %}
## Le tchat relié au jeu

Le salon **{{ site.lqdm.salon_tchat }}** est relié au jeu : ce que tu écris en jeu apparaît dans
ce salon, et ce qu'on écrit dans le salon s'affiche en jeu. La commande `/list` du Discord
montre qui est connecté.
{% endif %}
## Bon à savoir

- Les [règles](/wiki/regles/) du serveur s'appliquent aussi sur le Discord.
- Discord est réservé aux **13 ans et plus** : c'est une règle de Discord, pas de LQDM.
- Le Discord de LQDM a été créé par **{{ site.lqdm.createur_discord }}**.

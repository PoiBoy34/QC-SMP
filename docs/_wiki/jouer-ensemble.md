Sur LQDM, tout le monde joue dans le **même monde**, peu importe l'appareil : les joueurs sur PC
(Minecraft **Java**) et ceux sur Xbox, PlayStation, Switch, téléphone ou tablette (Minecraft
**Bedrock**). Vous vous voyez, vous vous parlez dans le tchat et vous construisez ensemble.

## Comment ça marche ?

Java et Bedrock sont deux versions différentes de Minecraft, qui d'habitude ne peuvent pas jouer
ensemble. Le serveur traduit en direct ce que fait chaque joueur pour l'autre version (grâce à
un outil appelé Geyser). Tu n'as rien à faire de spécial : connecte-toi comme d'habitude.

## Reconnaître les joueurs Bedrock

Le pseudo des joueurs Bedrock commence par un **point** : `.MonAmi`. Comme ça, le serveur ne
confond jamais un joueur Java et un joueur Bedrock qui auraient le même nom.

N'oublie pas le point dans les commandes : `/tpa .MonAmi`.

## Retrouver un ami

- Sur la survie : `/tpa Pseudo`, puis ton ami tape `/tpaccept`.
- Ou par le menu : **Rejoindre un ami**.
- Ton ami doit être sur le **même serveur** que toi (spawn, survie ou mini-jeu) : `/smp` vous
  emmène tous les deux sur la survie.

## Ce qui change un peu sur Bedrock

- Le **menu LQDM** s'ouvre avec `/menu` ou la boussole : il n'y a pas de bouton dans le menu
  pause des consoles. Il s'affiche comme une fenêtre de boutons.
- Les **items du serveur**, comme la poutine, ont aussi leur apparence sur Bedrock : accepte le
  pack de textures quand le jeu te le propose.
- Quelques détails d'affichage peuvent être un peu différents. Le jeu, lui, est le même pour tous.

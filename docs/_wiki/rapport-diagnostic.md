Le rapport de diagnostic contient tout ce qu'il faut pour comprendre un problème : ta version de
Windows, de Java et du launcher, la mémoire, les mods, les dernières erreurs. Il ne contient
**pas** ton mot de passe.

## Copier le rapport

1. Dans le launcher, ouvre **⚙️ Paramètres** (en haut à droite), ou clique sur la tuile **Aide**.
2. Dans **Aide et diagnostic**, clique sur **Copier le rapport de diagnostic**.
3. Colle-le dans ton message avec <kbd>Ctrl</kbd> + <kbd>V</kbd>.

## L'envoyer

Dans le salon **#support** du [Discord]({{ site.lqdm.discord }}), ou en message privé à
**{{ site.lqdm.contact }}**. Ajoute une capture d'écran du message d'erreur et dis ce que tu faisais
quand c'est arrivé.

Le rapport est trop long pour Discord ? Utilise **Enregistrer le rapport (.txt)** juste en dessous,
puis envoie le fichier.

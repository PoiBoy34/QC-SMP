Sur téléphone et tablette (Android, iPhone, iPad), et avec Minecraft pour Windows (Bedrock), tu
peux ajouter le serveur directement.

1. Dans Minecraft : **Jouer**, onglet **Serveurs**, puis tout en bas **Ajouter un serveur**.
2. Nom : ce que tu veux. Adresse : `{{ site.lqdm.adresse }}`. Port : `{{ site.lqdm.port_bedrock }}`.
3. Enregistre, puis touche le serveur pour le rejoindre.
4. Accepte le **pack de textures** si le jeu te le propose : c'est lui qui affiche les items du serveur.

Ton pseudo en jeu, c'est ton **gamertag**, avec un point devant (par exemple `.MonGamertag`).
C'est normal : le point montre aux autres que tu joues sur Bedrock.

Sur Xbox, PlayStation et Switch, le jeu ne permet pas d'ajouter un serveur à la main. On passe
donc par l'onglet **Amis** : le serveur a son propre compte Xbox, et il suffit de l'ajouter en ami.

## Les étapes

1. Dans Minecraft : **Jouer**, onglet **Amis**, puis **Ajouter un ami**.
2. Cherche le compte du serveur{% if site.lqdm.gamertag != "" %} : **{{ site.lqdm.gamertag }}**{% else %} (son nom est annoncé sur le Discord et sur la page [Jouer](/jouer/#console)){% endif %}.
3. Attends une minute : le serveur accepte ta demande tout seul.
4. Retourne dans l'onglet **Amis** : le serveur apparaît dans les parties qu'on peut rejoindre.
   Sélectionne-le et clique sur **Rejoindre**.

## Avant de commencer

- Minecraft doit être **à jour** et connecté à ton **compte Microsoft**.
- Sur PlayStation et Switch, le jeu en ligne peut demander un abonnement (PS Plus, Nintendo
  Switch Online).
- Avec un **compte enfant**, un parent doit autoriser le multijoueur, le jeu multiplateforme et
  les amis. Voir [Le serveur n'apparaît pas sur ma console](/wiki/probleme-console/).

Et n'oublie pas : il faut être sur la [liste blanche](/wiki/liste-blanche/) avec ton gamertag.

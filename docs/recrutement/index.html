Rejoins l'équipe

LQDM, c'est un projet entre amis. Tu veux donner un coup de main ?

{%- if site.lqdm.recrutement_ouvert %} Recrutement ouvert {%- else %} Recrutement fermé pour le moment {%- endif %}
🛡️

Modération

Aider les joueurs qui débutent, répondre dans #support et faire respecter les règles, dans le jeu comme sur Discord.

🧱

Construction

Construire le spawn, les décors des tournages et les cartes des mini-jeux, en équipe.

🎉

Animation

Imaginer et organiser des événements : concours de construction, chasses au trésor, soirées mini-jeux.

Ce qu'on cherche

  • Être actif sur le serveur et sur le Discord.
  • Être respectueux avec tout le monde, même quand ça chauffe.
  • Avoir envie d'aider : pas besoin d'être un expert, on apprend ensemble.

Comment postuler

Écris à {{ site.lqdm.contact }} sur Discord avec :

  • ton pseudo Minecraft (ou ton gamertag) ;
  • le rôle qui t'intéresse ;
  • pourquoi tu veux aider LQDM ;
  • pour la construction : quelques captures de tes créations.

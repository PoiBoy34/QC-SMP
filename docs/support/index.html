    Pour qu'on t'aide plus vite

    Dans ton message, donne-nous :

    • Sur quoi tu joues : PC, Xbox, PlayStation, Switch, téléphone…
    • Ton pseudo Minecraft, ou ton gamertag si tu joues sur console ou téléphone.
    • Ce qui se passe, avec une capture d'écran du message d'erreur.
    • Le rapport du launcher si tu joues sur PC (voir à côté).

    Le rapport du launcher

    Il contient tout ce qu'il faut pour comprendre un problème sur PC.

    1. Dans le launcher, ouvre ⚙️ Paramètres.
    2. Descends jusqu'à Aide et diagnostic.
    3. Clique sur Copier le rapport de diagnostic.
    4. Colle-le dans ton message avec Ctrl + V.

    Signaler un joueur

    Quelqu'un ne respecte pas les règles ? Ne réponds pas aux provocations : prends une capture d'écran, puis préviens-nous dans #support ou écris à {{ site.lqdm.contact }}.
